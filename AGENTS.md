# 小红书热点研究功能入口

当用户明确要求安装、配置或启用本项目时，读取并执行 [START.md](START.md)；英文请求使用 [START.en.md](START.en.md)。这是面向能运行工具的机器人的安装流程；不要只回复安装教程，也不要把文件下载成功说成已经接通账号。
